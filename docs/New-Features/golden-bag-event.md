# Feature-Idee: Goldener Beutel

## 1. Spieleraktion
Der Spieler betritt einen Raum und sieht einen offen liegenden Beutel voller Gold. Er kann ihn nehmen und dafür riskieren, dass irgendwo auf der aktuellen Etage ein Guardian erwacht, oder ihn liegen lassen und unverletzt weitergehen.

## 2. Kernidee
Ein einstufiger Event mit zwei Wahlmöglichkeiten:
- Gold nehmen: 100 + 25 × Tiefe Gold. Dabei besteht die Gefahr, dass auf der aktuellen Etage ein Guardian (spawnMob 4) geweckt wird.
- Den Beutel ignorieren und weitermachen.

Der Event wird maximal einmal pro Run angeboten und nur in den ersten fünf Regionen (Tiefen 1–25) ausgespielt.

## 3. Zweck der Idee
Mehr Abwechslung in der Erkundung und eine einfache Möglichkeit, frühe Goldreserven aufzubauen — mit einem echten, wenn auch verzögerten Preis in Form eines zusätzlichen Kampfes auf der Etage.
