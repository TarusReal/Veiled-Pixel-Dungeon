# Feature-Idee: Zwillingswaffen

## 1. Spieleraktion
Der Spieler findet zwei Waffen, die im Boden stecken. Er kann eine der beiden nehmen oder beide liegen lassen. Die gewählte Waffe wird sofort ausgerüstet — die bisherige Waffe wandert ins Inventar, falls Platz ist, sonst fällt sie auf den Boden.

## 2. Kernidee
- Zwei verschiedene Nahkampfwaffen werden zufällig aus dem gesamten Waffenpool ausgewählt.
- Die Waffen-Tiers orientieren sich an der Region (±1 Stufe Zufall). Höherer Tier bedeutet weniger Upgrades, niedrigerer Tier mehr Upgrades — so bleibt die Gesamtstärke ausgewogen.
- Die gewählte Waffe hat eine 50% Chance, mit einem starken Fluch belegt zu sein, der zwei Schriftrollen des Fluchbrechers erfordert, um entfernt zu werden.
- Die Waffe wird direkt ausgerüstet, was bei einem Fluch ein echtes Risiko darstellt, da die bisherige Waffe ins Inventar oder auf den Boden geht.
- "Beide liegen lassen" gibt keine Belohnung.

## 3. Zweck der Idee
Mehr Abwechslung bei der Waffenauswahl und ein riskanter, aber potenziell lohnender Fund. Die Tier/Upgrade-Abwägung und der starke Fluch sorgen für strategische Entscheidungen.
